# Auditoría de Rendimiento y Prevención de Excesos en Supabase

> Suite de diagnóstico integral para Supabase / PostgreSQL para auditar consultas lentas, alto consumo de Egress, índices faltantes y sobrecrecimiento de tablas.

## Uso

Pega [`diagnose-db-health.sql`](./diagnose-db-health.sql) en el **SQL Editor** del panel de Supabase o ejecuta:

```bash
bash audit.sh --db "postgresql://..."
```
