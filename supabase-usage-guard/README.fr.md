# Audit de Santé et de Performance Base de Données Supabase

> Suite de diagnostic complète pour Supabase / PostgreSQL : analyse des requêtes lentes, détection du trafic sortant (Egress) excessif, index manquants et fragmentation.

## Utilisation

Collez le contenu de [`diagnose-db-health.sql`](./diagnose-db-health.sql) dans l'éditeur **SQL Editor** de Supabase ou exécutez :

```bash
bash audit.sh --db "postgresql://..."
```
