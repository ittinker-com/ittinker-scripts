# Инструмент Диагностики Доступности VPS и Блокировок GFW

> Многорегиональный инструмент для разработчиков и системных администраторов, позволяющий мгновенно определить: упал ли сервер, закрыты ли порты файрволом или IP заблокирован цензурой (GFW).

## Зачем Нужен Этот Инструмент?

Когда VPS внезапно перестает отвечать, часто возникает путаница:
- Завис ли сервер или произошла перезагрузка?
- Сломалась ли конфигурация SSH?
- Заблокировал ли файрвол входящие пакеты?
- Или IP-адрес попал под целевую блокировку Великого Китайского Файрвола (GFW)?

Вместо ручной проверки десятка онлайн-сервисов, `diagnose.sh` опрашивает глобальные публичные зонды (Китай, США, Германия, Япония) прямо из вашего терминала и выдает точный диагноз.

## Таблица Диагностики

| Локальный Ping | Зонды в Китае | Зарубежные зонды | Тест порта | Вердикт и Рекомендации |
| :--- | :--- | :--- | :--- | :--- |
| ❌ Таймаут | ❌ Таймаут | ✅ Доступен | ❌ Недоступен в CN | **IP Заблокирован (GFW)**: Запросите смену IP у провайдера или настройте Cloudflare Tunnel / CDN. |
| ✅ Доступен | ✅ Доступен | ✅ Доступен | ❌ Ошибка подключения | **Порт закрыт / Файрвол**: Проверьте UFW, iptables и Security Groups в панели хостинга. |
| ❌ Таймаут | ❌ Таймаут | ❌ Таймаут | ❌ Таймаут | **Сервер отключен / Сбой сети**: Проверьте панель провайдера, VNC-консоль или перезагрузите ОС. |
| ✅ Доступен | ✅ Доступен | ✅ Доступен | ✅ Успешно | **Сервер в норме**: Проблема в локальном прокси, DNS или локальных SSH-ключах. |

## Использование

```bash
# 1. Проверка по IP (Порт по умолчанию: 22)
bash diagnose.sh 1.2.3.4

# 2. Проверка определенного порта (например, HTTPS 443)
bash diagnose.sh myvps.example.com -p 443
```
