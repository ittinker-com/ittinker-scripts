# Инициализация VPS в 1 клик

> Комплексный скрипт для настройки чистого сервера (Ubuntu/Debian) до безопасного рабочего состояния.

## Что выполняет скрипт:
1. Обновление ОС и ядра (`apt full-upgrade`)
2. Установка необходимых утилит (`curl, git, htop, ufw, fail2ban` и др.)
3. Создание непривилегированного пользователя с доступом к `sudo`
4. Усиление SSH (нестандартный порт, запрет входа root, только вход по ключам)
5. Настройка файрвола UFW (блокировка входящих по умолчанию)
6. Включение алгоритма ускорения сети TCP BBR
7. Настройка защиты от перебора паролей fail2ban
8. Установка правильного часового пояса

## Запуск

```bash
sudo bash init.sh
```
