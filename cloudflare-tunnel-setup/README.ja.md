# Cloudflare Tunnel ワンクリック自動構築ツール

> cloudflared をダウンロードし、systemd サービスとして自動登録します。インバウンドポートを一切開放せずに安全なアクセス環境を構築できます。

sudo bash setup.sh --token "YOUR_TUNNEL_TOKEN"
