# 零依賴極簡 VPS 健康檢查與告警腳本

> 專為獨立開發者設計的極簡無服務監控工具。純原生 Bash 編寫，無需常駐守護行程，超閾值時即刻推送 Telegram / Discord / 飛書 告警。

```bash
export TG_CHAT_ID="你的ChatID"
bash monitor.sh
```
